# **MyResearchExperience 📚**

记录和分享一些个人在科研过程中的经验、心得与思考。如果能够为你带来一点帮助，我会非常开心！

## **✨ 写在前面**

导师放养的科研之路确实是痛苦的。我的第一篇论文，从最初开始尝试到最终中稿，大概花费了两年半的时间。而距离我第一次走进这个实验室，也已经过去了将近四年。 期间经历了大大小小十几次拒稿，某种意义上也算是经历了一场**面向 Reviewer 的强化学习**。虽然过程痛苦而曲折，但也确实在一次次试错和修改中积累了一些经验。

从找 Idea，到实验设计、论文写作和投稿，每个阶段都会遇到各种各样的问题，也逐渐形成了一些自己的理解和习惯。创建这个仓库，是希望把这些零散的经验和心得整理、记录下来，能够分享给刚刚开始接触科研或者正在经历和我一样痛苦的同学。

这里的内容更多是总结我个人的经验、理解和一些偏好，并非什么标准答案。如果这些内容能够给大家带来一点启发或帮助，那这个仓库就已经很有意义了。
